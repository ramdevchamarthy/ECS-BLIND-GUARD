About the Smart Blind-Turn Safety System

📡

Live sensing

Two ultrasonic sensors detect a vehicle in sequence. The dashboard reads newline-delimited JSON telemetry from the Road ESP32 over USB serial.

🧭

Road geometry

Road A is represented as a 60 cm model. S1 is at 10 cm, S2 at 30 cm, and the blind-turn section begins around 40 cm.

🚦

Risk indication

Travel-time assessment: under 3 seconds indicates danger; 3 to under 5 seconds indicates caution; 5 seconds or more indicates safe in this prototype.

🛡️

Safety note

Screen colours and alerts are dashboard indications. Physical automatic braking only works when compatible Car ESP32 firmware, motor-driver wiring, and a verified control path are implemented and tested.

System architecture / data flow
1 · Road sensorsHC-SR04 Sensor 1 + Sensor 2
→
2 · Road ESP32Reads distance and sends newline-delimited JSON
→
3 · DashboardUSB Serial · 115200 baud · status and risk display

Separate vehicle-side components include the Car ESP32, LCD, motor driver and motors. The web dashboard does not itself command the motor driver unless a separate, compatible and verified control path is implemented.

Telemetry and prototype rules

Only sensor readings strictly below 18 cm are treated as valid detections. Values at or above 18 cm are ignored for detection and risk calculations. The dashboard expects newline-delimited JSON from the Road ESP32 at 115200 baud.

Testing and validation

Use the live dashboard and Event Log to observe incoming readings, connection state and alert transitions during controlled bench testing. Record measured results from your own tests before reporting accuracy, response time or braking performance; no unverified performance figures are claimed here.

Prototype scope and limitations

This is an educational prototype using a small road model and ultrasonic sensors. Real-road deployment would require further engineering, validation, fail-safe design and environmental testing. Full-screen alerts are visual indicators, not proof of physical braking.

How to use / user manual

🔌

1. Connect the Road ESP32

Connect the Road ESP32 to your laptop with a USB data cable. Open this site in a supported desktop browser such as Chrome or Edge, then click CONNECT ROAD ESP32 and select the correct serial port.

📡

2. Check sensor readings

Open Sensors & Alerts to view Sensor 1 and Sensor 2 readings. In this prototype, only readings strictly below 18 cm count as valid detections.

🚘

3. Watch the road

Return to Overview + Live Road. The dashboard visualises the vehicle moving from S1 to S2 and toward the blind turn when valid telemetry is received.

🚦

4. Understand the alerts

Green / SAFE: 5 seconds or more. Yellow / CAUTION: 3 seconds to under 5 seconds. Flashing red / DANGER: under 3 seconds. Full-screen visual alerts clear after about 4.5 seconds.

🧾

5. Review activity

Open Event Log to inspect connection and system messages. If the readings do not update, check the USB data cable, selected serial port, firmware baud rate (115200), and that another app is not using the port.

🛡️

Safety and limitations

This web dashboard reads USB serial data from a locally connected Road ESP32. A public website opened on another device will not automatically receive that USB data. Screen alerts alone do not stop the vehicle; physical braking requires a compatible, verified Car ESP32 command path and motor-control firmware. Test with wheels lifted and keep hands clear of moving parts.

Public website / demonstration checklist
  1. Deploy the extracted folder with index.html at the root of a static host such as Netlify.
  2. Open the published URL in desktop Chrome or Edge and check all five tabs.
  3. For live readings, connect the Road ESP32 by USB to the same computer and grant serial-port permission.
  4. For a remote judge demo, prepare a recorded demonstration or implement a secure remote telemetry service; public hosting alone cannot forward local USB readings.
  5. Test the motor-control system separately with wheels lifted and the area clear. Do not rely on a dashboard overlay as a physical emergency stop.
